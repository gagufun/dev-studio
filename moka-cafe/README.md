# MOKA — навчальний демопроєкт

Концепт сайту меню невеликої кав’ярні та Telegram-бота для демонстрації сценарію замовлення. Це особистий портфоліо-проєкт, не сайт реального закладу. Назва, позиції й ціни вигадані для прикладу. Бот не приймає оплату та не оформлює реальних покупок.

## Файли

- `index.html` — статичний сайт меню. Працює на GitHub Pages і не потребує бібліотек.
- `bot/main.py` — Telegram-бот на Python та aiogram.
- `bot/requirements.txt` — залежність бота.
- `bot/.env.example` — назви змінних, які треба додати в налаштування хостингу.

## Підключити сайт до бота

1. Створи окремого бота через `@BotFather` і скопіюй username.
2. В `index.html` знайди `const BOT_USERNAME = "";`.
3. Впиши username без символу `@`, наприклад `const BOT_USERNAME = "my_demo_bot";`.
4. Завантаж сайт у GitHub. Кнопка «Замовити в Telegram» відкриватиме бота з параметром `start=menu`.

До налаштування username кнопка вимкнена, щоб не вести на вигаданий бот.

## Запустити бота локально у Windows PowerShell

Потрібен Python. У PowerShell відкрий папку `projects/moka-cafe/bot` та виконай:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BOT_TOKEN="токен_окремого_бота"
$env:ADMIN_CHAT_ID="твій_числовий_Telegram_ID"
python main.py
```

Не вставляй токен NESSI. Не додавай реальний токен у файл або GitHub. Для запуску без пересилання адміністратору можна не задавати `ADMIN_CHAT_ID`; бот чесно повідомить, що замовлення залишилося лише тестовим.

Щоб перевірити доставку адміністратору, спершу напиши новому боту `/start` зі свого Telegram-акаунта, а тоді задай свій числовий ID у `ADMIN_CHAT_ID`. Бот надсилає адміністратору лише вибрані тестові позиції та суму; ім’я, телефон і платіжні дані не збираються.

## Розміщення

**Сайт:** завантаж папку `projects/moka-cafe/` у репозиторій `dev-studio`. GitHub Pages опублікує `index.html` як звичайну статичну сторінку.

**Бот:** GitHub Pages не запускає Python. Створи окремий Python-сервіс на хостингу, задай робочу папку `projects/moka-cafe/bot`, встановлення залежностей `pip install -r requirements.txt` і команду запуску `python main.py`. У налаштуваннях сервісу додай `BOT_TOKEN` та, якщо потрібна пересилка, `ADMIN_CHAT_ID` як змінні середовища. Секретні значення не записуй у репозиторій.

Замовлення для демо зберігаються в SQLite-файлі `moka_orders.sqlite3` на хості. Для навчального запуску цього достатньо; перед реальним використанням потрібні окрема перевірка бізнес-процесу, приватності та надійного зберігання даних.
